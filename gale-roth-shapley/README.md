## Overview
Implementation and analysis of two-sided matching markets with preferences:
- **Gale–Shapley Deferred Acceptance Algorithm**: Computes stable matches for one-to-one and many-to-one pairings.
- **Roth–Peranson Variant**: Extensions for market clearing and complex constraints (e.g., couple matching in hospital-resident matches).
- **Properties Analyzed**: Stability, student/proposer-optimality, receiver-pessimality, and blocking pair verification.
