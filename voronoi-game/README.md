# Module 3: Voronoi Volume Game

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Jordi-Ab/inter-university-algorithms/main?labpath=voronoi-game)

## Overview
Strategic generator/site placement game based on Voronoi cell partitioning and volume maximization:
- **Game Mechanics**: Players sequentially place point generators within bounded regions to capture maximum Voronoi cell territory.
- **Solvers & Strategies**: Heuristic, greedy, and minimax/Monte-Carlo agent strategies.
- **Interactive Visualization**: Real-time rendering of Voronoi tessellations, cell area/volume calculation via polygon clipping, and match scoring.
